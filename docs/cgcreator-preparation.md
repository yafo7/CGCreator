# 制作准备层

CGCreator 的制作准备层位于演出导演之前。它保存用户要控制的角色、道具和动作，而不是把它们作为一次导演生成时的临时副作用。

每个资源有稳定的 `assetId` 和可追加的不可变版本。一个版本保存完整的 3d-generate `modelJson`、上游 `_meta`、碰撞资料、语义取景资料和能力检查结果。确认的演出保存冻结的模型快照；编辑资源产生新版本，只使新的候选演出需要重新编译和验证。

生成描述必须是用户可见、可编辑的一句话，例如“穿蓝色短衫的少年”、“一把深色木椅”或“原地跑步”。复杂剧情、路线、接触、镜头和时间关系属于 DirectorDocument 与编译器，不会被拼成长提示词发送给 3d-generate。风格参考通过正式 `refs` 参数传入，最多三个，且仅使用带 `_meta.ai` 的生成模型。

动作绑定到具体模型版本。生成服务采用返回的自然 `baked.duration`，时间轴随后决定循环、保持和重定时；请求时长不再被当作上游控制参数。模型版本改变时，旧动作不自动冒充兼容。

工作区提供三条资源入口：一句话制作角色或道具、一句话制作动作、以及从完整 3d-generate 编辑器导入模型 JSON。导入结果由选中的准备资源接收，创建新版本，不覆盖旧版本。当前 3D 资产工坊由本地 sibling `3d-generate` 在需要时启动；它的完整保存系统仍在该工具中运行，CGCreator 的可靠回传方式是导出模型 JSON 后点“导入编辑结果”。

资源准备发生在项目 CAS 锁之外，远程生成结果先进入本地资源缓存；若用户在等待期间编辑了项目，结果不会写入过期项目，但同一请求可以复用缓存。
